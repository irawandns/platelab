# Saved plates

Add food, then choose **Save plate** above the plate. A name is suggested for you;
keep it or enter your own, then choose **Save**.

Choose **Saved plates** to find your meals. Each one shows its food count and
estimated energy. **Load plate** restores the meal; **Undo last change** brings
back the plate you were working on. **Delete** asks you to confirm and removes
only the saved copy.

## What is saved

Food, portions, oil settings, plate style and size, food forms, selection, and
positions/rotations are retained. Nutrition is recalculated from the current food
data; unknown nutrients remain unknown. The kitchen playground and camera are
not saved. Each save creates a separate copy.

Existing experiments saved before this update are kept. Loading one restores its
changed plate; the comparison interface is no longer shown. The original data
are retained in storage for compatibility.

## Storage

Up to ten plates are saved in this browser on this site. There is no account or
cloud sync. Clearing site data, private-browsing cleanup, or browser eviction can
remove them. Unsaved work resets on reload.

If storage is full or blocked, saving reports an error and preserves the entered
name and current meal. Allow site storage or free space and try again. At ten
plates, delete an old saved plate to make room.

Unavailable foods or unsupported saved details disable loading for that entry;
you can still delete it explicitly. An unreadable storage document is left
untouched. Other tabs refresh their displayed list when storage changes; this is
not a conflict-resolution system for simultaneous saves.

The save and load windows support keyboard use, Escape, focus restoration, and
the non-WebGL fallback. Deleting saved copies cannot be undone; loading can.
